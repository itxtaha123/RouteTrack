# 🗺️ RouteTrack

> A modern route-tracking project designed to make everyday travel between home and college easier to monitor.

## ✨ Highlights

- 📍 Route and location tracking
- 📱 Mobile-friendly experience
- 🔐 User-focused access and authentication
- 🧭 Designed around real-world daily routes
- 🚀 Built as an evolving project

## 🎯 Project Goal

RouteTrack explores how software and location technology can be combined to create a simple, useful travel companion for students and everyday commuters.
